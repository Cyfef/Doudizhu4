# Doudizhu4

一个支持 PC 与移动端浏览器的四人两副牌斗地主游戏。项目采用本地 Node.js 服务运行，支持房间对局、机器人玩家、房主设置、断线重连、对局历史记录，以及适配横屏移动设备的牌桌界面。

## 运行方式

请先安装 [Node.js](https://nodejs.org/)，然后在项目目录运行：

```bash
npm start
```

服务默认监听 `8080` 端口：

- 本机访问：`http://localhost:8080`
- 局域网设备访问：`http://电脑的局域网 IP:8080`

Windows 用户也可以双击 `start-host.bat` 启动。若需要让同一局域网中的手机或平板连接，请先以管理员身份运行一次 `allow-firewall.bat`。

## 测试

```bash
npm test
```

## 版本分支

- `main`：当前最新稳定版本
- `v1`：第一个稳定版本快照

后续版本将继续以 `v2`、`v3` 等分支留档，同时保持 `main` 为最新版本。
